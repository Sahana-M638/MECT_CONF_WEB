# MECT Conference Website

## Description

A responsive conference website developed to provide complete information about the MECT International Conference. The website enables participants to explore conference details, committee members, keynote speakers, paper submission guidelines, registration information, important dates, and contact details through a clean and user-friendly interface.

## Features

* Responsive web design
* Conference overview
* Committee members
* Keynote speakers
* Call for papers
* Important dates
* Registration details
* Contact information
* User-friendly navigation

## Tech Stack

* HTML5
* CSS3
* JavaScript
